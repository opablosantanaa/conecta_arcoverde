# Conecta Arcoverde

Plataforma de empregabilidade da Prefeitura Municipal de Arcoverde-PE.
Conecta candidatos a vagas de emprego com gestão administrativa pela ACA (Agência de Cidadania e Assistência) e Prefeitura.

## 🏗️ Arquitetura

- **Backend**: Java 17 + Spring Boot 3.2 + Spring Security + JWT + MySQL 8
- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS
- **Infraestrutura**: Docker + Docker Compose

## 📋 Pré-requisitos

- Java 17+
- Maven 3.9+
- Node.js 18+
- Docker e Docker Compose
